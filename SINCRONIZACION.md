# Sincronización web ↔ app

La lógica de `src/context`, `src/lib`, `src/data`, `src/types` y `src/hooks` se comparte con la app móvil (`../dailyset-app`).
Edítala aquí y, desde `dailyset-app`, ejecuta `npm run sync:web`.
